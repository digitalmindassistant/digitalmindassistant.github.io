DIGITAL MIND

Privacy Policy

This policy explains how the privately operated Digital Mind application accesses, uses, stores, and shares information, including data received from Google APIs.

Effective October 17, 2026

1. Scope and availability

Digital Mind is a personal productivity application designed to capture and organize information such as notes, tasks, research ideas, links, and reminders. It is currently privately operated, in development, and not generally available to the public. There is no public account-registration or signup service.

This policy applies to the Digital Mind application and its use of Google APIs. This public informational website does not use analytics, advertising technology, cookies, or account registration.

2. Google data accessed

Gmail read-only access

When the user explicitly connects Gmail, Digital Mind uses read-only Gmail access to locate and retrieve qualifying Google Voice message-notification emails used for personal capture. The application uses the message sender, received timestamp, Gmail message identifier, and extracted message text to create and deduplicate local entries.

Digital Mind does not request or store the user's Gmail password. Its Gmail integration does not send, modify, archive, or delete Gmail messages.

Google Calendar access

When the user separately connects Google Calendar, Digital Mind uses Calendar access to identify an explicitly selected calendar and to create and manage reminder events requested by the user. Digital Mind stores the selected calendar's identifier and relevant event identifiers so it can avoid duplicate events and update or cancel events it created.

Digital Mind does not use Calendar authorization to modify unrelated events. Gmail and Calendar authorization are separate, and connecting one does not silently grant access to the other.

Google API Limited Use

Digital Mind's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. How information is used

Information obtained through Google APIs is used only to provide the user-facing features described above:

  • capturing qualifying Google Voice notifications as local Digital Mind entries;
  • preserving source identifiers and timestamps for duplicate prevention and reminder timing;
  • identifying the calendar selected by the user; and
  • creating, updating, reconciling, or canceling user-requested reminder events that Digital Mind manages.

Digital Mind does not use Google user data for advertising, credit decisions, surveillance, or unrelated profiling.

4. Local storage and retention

Captured entries, integration settings, source identifiers, and authorization credentials are stored locally on the user's Windows computer. Application records are stored in a local SQLite database. OAuth client configuration and tokens are kept in local application data paths. OAuth tokens use the application's Windows current-user protected storage.

Digital Mind does not operate a hosted database for this personal installation. Local records remain until the user edits or deletes them, removes the local application data, or disconnects an integration as applicable. Revoking Google access prevents future API access but does not automatically delete information already stored locally.

No storage method can be guaranteed to eliminate every risk. The user is responsible for controlling access to the computer, backups, and local application files.

5. Sharing, sales, and advertising

Digital Mind does not sell personal information and does not use personal information for advertising. It does not share Google user data with data brokers, advertisers, or analytics providers.

Data is exchanged with Google only as needed to make authorized Gmail or Calendar API requests initiated by the application's configured synchronization and reminder features.

6. Your choices and controls

The user can disconnect Google Calendar from within Digital Mind. Gmail and Calendar authorization can also be reviewed or revoked from the third-party connections page in Google Account settings.

The user can review, edit, archive, or delete captured entries within Digital Mind. Local application files and backups remain under the user's control and must be managed separately.

7. Changes to this policy

This policy may be updated as Digital Mind's functionality or data practices change. The effective date at the top of this page will be updated when material revisions are published. Digital Mind will not use Google user data for a materially different purpose without updating the relevant disclosure and obtaining any consent required by applicable Google policies.

8. Contact

Digital Mind is privately operated. Project-owner information and the public website repository are available through the Digital Mind GitHub profile.
